# Mosaico 学习助手

把 ESP-Mosaico 变成一台可以拍题、听问题、讲步骤的随身学习助手。浅色毛玻璃界面，配合实体 AI 键和触摸操作，按自己的节奏看、听、继续问。

## 拍题：先选中，再讲解

拍清题号与完整题干，点击“识别题目”。一张照片拍到多道题时，会先列出题号、题干片段及位置；每页三题，可翻页，点选后才开始讲解。没有题号时按顺序标记。讲解页可换一题，继续使用同一张照片。

支持实时横向取景、插件 LED 补光，以及独立的 180° 镜头朝向补偿。预览与拍下的照片保持一致；拍照结束或离开相机时自动关灯。

## 语音：识别文字，确认后提问

点大麦克风／声波或“开始说话”，也可以按住顶部 AI 键录音。录音期间平滑 wave 持续活动。结束后先显示识别文字，支持翻页检查、重说或取消；只有点击“确认发送”才请求问答。刚才的题没听懂，可以继续追问，保留所选题和原图上下文。

## 看得清，也能听

回答支持上一页／下一页和分步讲解。可手动朗读、停止；关闭“自动朗读”后，新回答不自动播放，手动点朗读仍然有效。

从屏幕顶部下拉，调整亮度、音量、自动朗读，以及自动旋转／固定方向；向上滑动收起。齿轮进入连接设置。年级可选一年级到高三，用于提示模型采用相应知识难度与表达；目前不绑定教材版本或学期。

## 下载兼容性：旧版 ABI 1 手动安装包

本次发布保留已经实机验证的固件：Recovery ABI 1、分区布局版本 4、`esp-iris-system-update/v1`。下载的是 ZIP，内含原始完整 `.irisfw`、安装说明及校验值，不生成六位安装码。

**只适用于仍使用匹配旧版 Recovery 的设备。Vibe Mode 0.2 / ABI 2 设备不可直接安装，也不要降级基础固件来尝试。** 官方 0.2 工具不兼容旧包；不能修改版本字符串冒充新格式。新版 Vibe Mode 适配不包含在此版本中。

[平台附件格式说明](https://mosaico.ai/zh-hans/faq)支持 ZIP 下载后自行安装。安装前请阅读包内 `INSTALL_CN.md`，使用匹配的旧版官方工具确认设备与布局，保留 Recovery、身份及个人配置。

## 开始使用

- 硬件：ESP-Mosaico（ESP32-S31）。拍题需要摄像头插件，使用左侧插槽；语音使用板载麦克风与扬声器。
- 下载并解压 ZIP，按包内安装说明，用匹配旧版的官方 `mosaico.py iris system-update --bundle` 安装完整 `.irisfw`。包含应用与界面资源，请勿只刷应用 `.bin`。
- 首次使用或下拉齿轮进入手机配置后，手机连接设备显示的 Learn-Setup 热点，打开 192.168.4.1，选择家中 Wi-Fi，填写自己的阿里云百炼 API Key，并测试连接。
- 本应用需要联网。照片识别、语音识别、讲解和合成朗读调用云端模型，产生的模型费用由所配置账户承担。语音的“确认发送”控制问答提交，语音识别本身也需要联网。

首个公开版本 v1.0.0（2026-10-23，多题选题功能版）。多题识别后选择、同图换题及围绕当前题追问，均已完成实机确认。

说明影片根据用户提供的实机影片和照片剪辑；网络等待和重复操作已压缩。标为“界面示意”的选题页来自原生界面预览，使用演示题目；不将其当作真实试卷识别结果。影片配有 MiniMax 合成的普通话旁白，按操作步骤对齐；原片室内音轨未公开。设备问答仍使用自行配置的阿里云百炼服务，影片配音不改变设备模型设置。
