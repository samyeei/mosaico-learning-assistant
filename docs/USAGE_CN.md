# Mosaico 学习助手：从配网到日常使用

适用版本：v1.1.0，Vibe Mode 0.2 / ABI 2 多题选题版。第一次建议由家长完成设置，之后孩子日常使用不需要手机。

## 1. 先准备好

- 一台已经安装学习助手的 ESP-Mosaico、一部能连接 Wi-Fi 的手机，以及可上网的家庭 2.4 GHz Wi-Fi。
- 拍题需要摄像头插件，安装在设备左侧插槽。安装前关闭设备，确认接口方向正确，不要强插。
- 一个阿里云百炼账号和自己的模型 API Key。云模型调用按所配置账号的额度与计费规则结算。

如果还没有安装：先阅读[安装说明](../firmware/INSTALL_CN.md)。新版完整 `.irisfw` 面向 Vibe Mode 0.2 / ABI 2。平台审核通过并生成六位安装码后，可在设备 Vibe Mode 中输入项目页公布的安装码安装；审核前可用匹配的官方 0.2 工具安装完整包。仍为 ABI 1 的旧设备需先按[迁移说明](MIGRATION_02_CN.md)升级基础固件。不要用旧版 v1.0.0 存档包替代新版，也不要只刷应用 bin。

## 2. 去哪里获取 API Key

设备设置页中的 **API Key / Token 是同一个输入项**，填写的是阿里云百炼模型调用密钥。不要填阿里云登录密码、AccessKey ID/Secret、ChatGPT 密钥或 MiniMax Token。MiniMax 只用于本项目说明影片配音，不是设备问答的服务商。

1. 手机或电脑打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，登录自己的账号；首次使用按控制台提示完成所需的账号验证和服务开通。
2. 打开 [北京地域 API Key 页面](https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key)。确认右上角地域为“华北2（北京）”；若使用新加坡账号/服务，可打开[新加坡 API Key 页面](https://bailian.console.aliyun.com/ap-southeast-1/model/settings/api-key)，并在设备配置时也选新加坡。
3. 已有可用 Key 可以复制；新建时点击“创建 API Key”，选择自己有权限的账号、业务空间并确认。个人首次设置可从默认业务空间开始；创建权限不足时需账号管理员处理。
4. 复制完整 Key，通常以 `sk-` 开头。不要只复制列表里的掩码或省略号。自定义模型权限需覆盖本应用用到的视觉、语音识别和语音合成模型。

创建入口、权限选项和页面名称以阿里云当前页面为准，详见 [官方获取 Key 说明](https://help.aliyun.com/zh/model-studio/get-api-key/)。不同地域的 Key 不能混用，详见 [官方地域说明](https://help.aliyun.com/zh/model-studio/regions/)。本版设置只支持北京/新加坡，使用内置 DashScope 接口，不需要输入 Base URL。

当前固件使用 `qwen3-vl-plus`（图片和问答）、`qwen3-asr-flash`（识别语音）、`qwen3-tts-flash`（朗读）。创建 Key 不需要在设备里逐个填模型名；可用权限和费用以账号实际情况为准。准备模型 API 的按量调用 Key，不能因为某种编程订阅也以 `sk-` 开头，就假定它能调用这三个模型。

请保管好 Key，不要发到项目评论、GitHub Issue、群聊或公开截图里；若泄漏，在百炼控制台停用/删除旧 Key，再创建并配置新 Key。

## 3. 手机先连接设备热点

1. 打开学习助手。首次未配置时，设备会引导进入“连接与设置”；已使用过的设备，可从屏幕顶部向下滑，点齿轮进入。
2. 点击“用手机配置 Wi-Fi 和 Token”。设备显示 `Learn-Setup-XXXX` 热点名称及 `192.168.4.1`。
3. 在手机的系统 Wi-Fi 设置里连接这个 **Learn-Setup 热点，无需密码**。若出现“无法上网”，选择继续保持连接；此时手机连的是设备，不是家中路由器。
4. 在手机浏览器地址栏输入 **http://192.168.4.1**，打开“连接你的学习助手”。不要输入到搜索框，也不要改成 https。若手机自动切走热点，重新连回 Learn-Setup 再打开。

日常使用时设备连接家庭 Wi-Fi；Learn-Setup 只用于配置。家庭路由器的 Wi-Fi 密码仍需正常填写。

## 4. 填入家庭 Wi-Fi 和 Token

保持手机连接设备热点，在网页依次操作：

| 页面字段/按钮 | 应该怎么填或点击 |
|---|---|
| 扫描附近 Wi-Fi | 点击后等待扫描，在“附近的 Wi-Fi”下拉框里选择家中的网络 |
| 家庭 Wi-Fi 名称 | 选择后自动带入；找不到时可手动输入准确名称 |
| Wi-Fi 密码 | 填家中路由器的密码；只有家中网络本身免密时才留空 |
| 大模型服务商 | 固定为“通义千问 Qwen · 阿里云百炼”，无需更改 |
| API Key 所属地域 | 北京 Key 选“中国内地（北京）”；新加坡 Key 选“国际（新加坡）” |
| API Key / Token | 粘贴刚才复制的完整百炼 `sk-...` Key；不要填网页地址或只填 `sk-` |

可用“显示”检查密码和 Key 是否粘贴完整；确认后隐藏，勿公开截图。Wi-Fi 名称、密码和 Key 不要使用本文的示例字符串代替。

### 先测试，再保存

1. 点击 **“测试 Wi-Fi 和 Token”**，等待网页依次检查联网、时间同步和模型连接。期间手机保持连接设备热点。
2. 出现“Wi-Fi 和 Token 测试通过，可以点击保存；尚未保存配置”，说明本次测试成功，但还没有写入配置。
3. 点击 **“保存配置”**。设备会再次测试，通过后保存并重启。看到配置成功及重启提示后，手机可切回家庭 Wi-Fi。
4. 设备回到首页后，查看右上角 Wi-Fi/API 状态；再分别试一次语音识别、图片讲解和朗读。配置测试不等于已经验证所有语音权限或每一道题的答案正确率。

以后换路由器或换 Key，重复“下拉 → 齿轮 → 用手机配置 Wi-Fi 和 Token”。

## 5. 拍题：先选题，再讲解

1. 首页点 **“拍题讲解”**，等待实时取景出现。把设备移动一下，确认预览随之变化。
2. 把题号、完整题干、选项及必要的图形拍清楚，尽量正对纸面，避免手挡住、反光和文字太小。
3. 光线不足时点快门左边的“补光”；摄像头翻到前面时，点快门右边的 180° 图标调整朝向。拍下的照片与取景一致。
4. 点击中间快门拍照。画面不清楚点“重拍”，清楚则点 **“识别题目”**。拍照完成或离开相机时补光灯会关闭。
5. 设备先展示题号和简短题干，每页三题。**核对后点击要讲的那一道，才开始讲解**；没有题号的题会按顺序标记。单题也先确认。
6. 列表有多页，用“上一页/下一页”查找；漏题或识别不对，点“没找到？重新拍照”，把目标题拍得更清楚。
7. 讲解后点“换一题”回到同张照片的列表，可选另一道题，无需重复拍照。

AI 识别和解题可能出错，请对照原题检查。密集题目拍得太远时，分区域拍摄通常更容易看清。

## 6. 语音提问：说完先看文字，确认才发问

1. 首页点 **“问个问题”**，进入语音页。
2. 点大麦克风/声波，或点“开始说话”，启动录音。录音时 wave 持续活动；再次点击结束。也可以按住顶部 AI 键说话，松开结束录音。
3. 等待语音识别，进入 **“识别确认”** 页。上下页检查识别文字是否正确。
4. 识别错了点“重新说”；不想问了可返回/取消。这里是识别文字确认，并非手机键盘编辑框。
5. 只有点击 **“确认发送”** 才提交文字问题请求回答。结束录音或松开 AI 键不会直接发送问答请求；语音识别过程本身需要联网。

讲解页的 **“继续提问”** 使用相同流程，回答会结合当前选中的题和原图。可问“为什么第二步要这样做”“能再举一个例子吗”。

## 7. 看回答、听朗读、调整设置

- **上一页/下一页**：翻阅当前回答；“换个讲法”可再解释一次。
- **朗读/停**：手动开始或停止朗读。关闭自动朗读后，手动点击仍可读；音量为 0 时需先调高音量。
- **从顶部下拉**：打开控制面板，调屏幕亮度、音量和“自动朗读”。开启后可自动读新回答，关闭后只显示文字，仍保留手动朗读。
- **方向锁图标**：在自动旋转与固定当前方向之间切换；固定后转动设备不会带着整页旋转。
- **向上滑**：关闭下拉面板，也可点“收起”。
- **齿轮 → 年级**：打开年级下拉菜单，上下滑动选择一年级至高三。年级用于提示讲解难度和用语，不保证严格对应某个教材、学期或课程进度。
- **返回**：使用页面左上角的大返回按钮。

## 8. 常见问题

| 遇到的情况 | 先这样处理 |
|---|---|
| 手机连上 Learn-Setup 却提示不能上网 | 配置热点本来不提供正常上网；保持连接，用浏览器打开 http://192.168.4.1 |
| 192.168.4.1 打不开 | 确认手机仍连设备热点、设备仍在配置页；在地址栏输入完整 http 地址，避免被自动切回其他网络 |
| 扫描不到家中 Wi-Fi | 使用 2.4 GHz 网络、靠近路由器，再扫描；也可准确手填名称 |
| Wi-Fi 连接失败 | 检查家庭 Wi-Fi 名称和密码，确认不是把 Learn-Setup 热点名填成家庭网络 |
| Key 格式不对或鉴权失败 | 重新复制完整百炼模型 API Key；核对北京/新加坡地域、Key 是否有效及账号权限 |
| Wi-Fi 已连接，模型却超时或安全连接失败 | 确认家庭网络能正常访问服务，再测试；保留屏幕完整提示便于定位。不要公开 Key |
| 问答正常，语音识别或朗读失败 | 检查相应 ASR/TTS 模型权限与账号额度；配置测试通过不代表语音接口一定通过 |
| 没声音 | 先调高音量，再手动点“朗读”；自动朗读开关只控制自动播放 |
| 一张照片识别成多题 | 这是正常流程；按题号和题干选要讲的那题，而不是直接讲全部 |
| 拍不到目标题或选错题 | 回列表换题；漏题则重拍，保留题号、图形和完整条件 |

照片、录音和问题会通过网络发送到所配置的云服务。请避免拍入姓名、学号或其他无关个人信息。云服务可用性和费用以账号与服务商规则为准。
