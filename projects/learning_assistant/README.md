# Learning assistant application

Application sources, shared native-C UI model, GSP 1.5.1 resources, device adapters and PC tests.

See the repository [README](../../README.md), [build guide](../../docs/BUILD_CN.md), and [license](../../LICENSE.md).
Version 1.1.0 targets Vibe Mode 0.2, Recovery ABI 2 and the esp-mosaico/v2 contract. The original 1.0.0 firmware remains a separate legacy ABI 1 artifact.
